## 四、依赖关系与使用顺序

```
① JDK ─────────────┐
                    ├──► ③ Maven 编译/打包 ──► ④ Spring Boot 启动
② Maven ───────────┘         │
                             └──► ⑤ 数据库（H2/MySQL）提供持久化
                                  └──► ⑥ Nacos（可选，单体可省）
                                              │
                                              ▼
                             ⑦ HTTP 接口：http://localhost:8080/api/**
                                              │
                    ┌─────────────────────────┘
                    ▼
⑧ Node + npm ──► ⑨ npm install 前端依赖
                    │
                    ▼
⑩ Vite dev server（:5173）──通过 proxy──► 后端 :8080
                    │
                    ▼
⑪ 浏览器访问 ──► ⑫ curl / puppeteer 回归验证
```

**顺序要点**

1. **JDK 与 Maven 是后端的前置**，两者缺一不可；Maven 通过 `JAVA_HOME` 找到 JDK。
2. **Maven 依赖先于 Spring Boot**：`mvn` 首次执行会把 Spring Boot / MyBatis-Plus 全部依赖拉到 `~/.m2/repository`（**首次约 200~400MB，耗时较长**，配镜像可大幅缩短）。
3. **数据库先于 Spring Boot 启动**：建表脚本与种子数据在应用启动时执行。
4. **Nacos 是可选前置**：只有启用 Spring Cloud Alibaba 服务发现时才需要；单体 Spring Boot 可直接跳过。
5. **前端依赖先于 Vite 启动**：`node_modules` 缺失时 `vite` 无法运行。
6. **联调顺序**：先确保后端 `:8080` 能独立用 `curl` 打通，再接前端，避免前后端同时排查。
