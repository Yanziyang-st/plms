# Mint PLM · 软件生命周期管理系统

以根目录 `README.md`（iBizPLM 介绍）为参考规格实现的软件生命周期管理系统，**技术栈与 README 保持一致**。

- 后端：Spring Boot + MyBatis-Plus + Nacos + Logback + Maven
- 前端：Vue 3 + vue-router + pinia + axios + element-plus
- 图表：**ECharts 6**（README 未指定图表方案，按需引入；详见 [功能清单.md](./功能清单.md) 第五章）

## 快速开始

### 1. 数据准备

MySQL 8 已就绪（`127.0.0.1:3306`，库 `plms`，`root/123456`）。建表与种子数据在应用启动时自动完成。

### 2. 启动后端

```bash
export JAVA_HOME="C:\Program Files\Microsoft\jdk-17.0.13.11-hotspot"
cd plms-service
unset SERVER__PORT          # 本机该环境变量会覆盖端口
mvn -Dmaven.repo.local=D:\apache-maven-3.8.1\repo spring-boot:run \
    -Dspring-boot.run.arguments=--server.port=8080
```

启用 Nacos 服务发现（可选）：

```bash
/d/nacos-server-2.5.4/nacos/bin/startup.cmd -m standalone
mvn ... -Dspring-boot.run.arguments="--server.port=8080 --spring.profiles.active=nacos"
```

### 3. 启动前端

**方式 A（推荐，双击即可）**

```
scripts\start-frontend.cmd            # 默认 5188 端口
scripts\start-frontend.cmd 5199       # 自定义端口
```

**方式 B（命令行）**

```bash
cd D:/plms
python scripts/dev-server.py 5188
```

**方式 C（标准 Vite 工作流，需能正常创建子进程的机器）**

```bash
cd plms-web && npm install && npm run dev    # http://127.0.0.1:5173
```

> Vite 的 `server.proxy` 已把 `/api` 代理到 `:8080`，因此**仍需先启动后端**。

#### Vite 模式常见问题

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| `The package "@esbuild/win32-x64" could not be found` | esbuild 通过 `optionalDependencies` 安装平台二进制，被 `--no-optional` / `--omit=optional` 或中断的安装跳过了 | 正常执行 `npm install`（不要加 `--no-optional`）；项目已内置 `.npmrc` 声明 `include=optional`。仍失败可显式安装：`npm i --no-save @esbuild/win32-x64@0.21.5` |
| `Component provided template option but runtime compilation is not supported` | 本项目组件全部用**运行时 template 字符串**（无 .vue 单文件组件），默认解析到的 `vue.runtime.esm-bundler.js` 不含编译器 | 已在 `vite.config.js` 配置 `alias: { vue: 'vue/dist/vue.esm-bundler.js' }`，**勿删除** |
| `Failed to resolve import "element-plus/zh-cn"` | 该子路径不在 element-plus 的 `exports` 映射内 | 已改用规范路径 `element-plus/es/locale/lang/zh-cn` |
| 页面能打开但接口 404/502 | 后端未启动，或代理目标不是 `127.0.0.1:8080` | 先启动后端，检查 `vite.config.js` 的 `server.proxy` |
| `npm install` 报 `spawnSync ... EBUSY` | 运行环境限制了创建子进程（容器/沙箱常见） | 改用方式 A/B（无需构建），或换普通终端安装 |

浏览器访问 **http://127.0.0.1:5188/index.html**

演示账号：`demo_admin / 123456`（管理员），其余账号密码同为 `123456`。

> 前端开发服务器同时承担两项职责：托管 `plms-web` 静态资源、把 `/api/**` 反向代理到后端 `:8080`。
> 因此**必须先启动后端**，否则页面会展示"无法连接服务端"的错误态（这是预期行为，用于验证错误处理链路）。
> 一键启动：`scripts\start-backend.cmd`（可选第 2 个参数传 `nacos` 启用服务注册）。

## 功能模块

| 模块 | 对接接口 | 覆盖能力 |
| --- | --- | --- |
| 工作台 | `/bootstrap`、`/metrics/overview` | 个人待办、交付趋势、需求分布、团队动态、项目进度 |
| 产品管理 | `/requirements`、`/products` | 产品切换、需求/工单列表（服务端分页筛选）、需求详情、需求跟踪矩阵、增删改 |
| 项目管理 | `/projects`、`/work-items`、`/sprints` | 项目集、看板（**拖拽改状态并联动项目进度**）、工作项列表、迭代、发布就绪度 |
| 测试管理 | `/test-cases`、`/test-plans` | 用例管理、结果标记、计划编排、**计划执行（失败自动建缺陷）**、测试报告 |
| 知识管理 | `/wiki-spaces`、`/wiki-pages` | 空间、页面树、Markdown 编辑与保存 |
| 效能度量 | `/metrics/overview`、`/metrics/members` | 燃尽图、速率、工作项分布、成员效能报表、CSV 导出 |
| 协作空间 | `/topics`、`/topics/{id}/comments` | 话题发布、讨论回帖、参与度统计 |
| 自动化 | `/automations` | 规则列表、启停、立即执行、模板创建、触发→条件→动作 |
| 智能协同 | `/agents` | 六类软件工程智能体 + AI 助手对话 |
| 后台管理 | `/users`、`/system/reset` | 成员与角色、权限矩阵、系统配置、演示数据重置 |

> **图表与详情**：全部图表使用 ECharts 实现，且**每个图表与面板都可点击进入详情视图**（含关键指标、大图、口径说明、数据明细、注意事项）。部分图表支持**图内下钻** —— 点击环形图扇区或柱状图元素直接进入该分类的详情。

## 设计规范：薄荷绿 × Liquid Glass

- 主色薄荷绿 `#23d3a9`，渐变 `#3fe3bd → #12b894`
- 对比色：天蓝 `#38bdf8` / 紫罗兰 `#8b7cf6` / 琥珀 `#ffb020` / 珊瑚 `#ff7a6b`
- 玻璃材质：`backdrop-filter: blur(20px) saturate(175%)` + 半透明白底 + 白色高光描边 + `inset` 内高光
- 背景：多层径向光晕缓慢流动，为磨砂玻璃提供可折射的内容
- 响应式：≥1240 四列 / ≥1020 两列 / ≤900 侧边栏收为图标 / ≤620 单列
- Element Plus 已按主题覆写（主色、按钮、表格、弹层、分页、标签等）
